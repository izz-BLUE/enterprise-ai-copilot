# 双服务架构说明

## 1. 架构定位

本项目采用 Java + Python 双服务架构。

Java Spring Boot 作为企业业务主系统，负责对外接口、用户权限、知识库管理、文档管理、审计日志和业务流程管理。

Python FastAPI 作为 AI Agent 服务，负责大模型调用、RAG 检索、LangChain / LangGraph 编排、Tool Calling 和 Prompt 管理。

## 2. 当前已完成链路

当前已完成健康检查链路：

客户端请求：

GET /api/agent/health

Java 后端调用：

http://localhost:8000/agent/health

Python Agent 返回：

{
  "service": "agent-python",
  "status": "UP"
}

## 3. 当前服务接口

Java 服务：

GET /api/health

Python Agent 服务：

GET /agent/health

Java 调 Python：

GET /api/agent/health

## 4. 后续扩展方向

后续将在 Python Agent 服务中增加 /agent/chat 接口，由 Java 后端统一转发用户问题，实现普通大模型对话、RAG 问答和 Agent 工具调用。
