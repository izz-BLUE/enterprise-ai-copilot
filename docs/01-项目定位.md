本项目是一套企业级 RAG + Agent 业务流程辅助平台，采用 Java + Python 双服务架构，Java 侧负责企业业务系统能力，Python 侧负责 RAG、Agent、Tool Calling 和大模型编排能力。

# 项目定位

本项目不是单纯的知识库问答 Demo，而是一套面向企业内部业务场景的 AI Copilot 平台。

项目采用 Java + Python 双服务架构：

- Java 侧负责企业级业务系统能力，包括用户权限、知识库管理、文档管理、文档版本、审计日志、业务流程模板等。
- Python 侧负责 AI 能力，包括 RAG、Agent、Tool Calling、Prompt 编排、低置信度拒答和引用来源返回。

项目支持多个业务域：

1. 银行业务制度问答
2. 企业 HR / 行政制度问答
3. IT 运维知识库问答
4. 智能客服工单辅助

项目目标是证明开发者具备将大模型能力落地到企业业务系统中的工程能力。
